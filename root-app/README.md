# Velceron Root App dashboard prototype

This folder is a **separate Root App UI prototype**. It does not replace or modify the existing Root Bot entry point or manifest.

## Important architecture boundary

Root documents Apps and Bots as separate project types, each with its own server and database instance per installed community. The current Velceron Bot stays in the repository root. The UI component is intentionally kept under `root-app/client/` so it can be moved into the client generated by Root's official App starter.

## UI included

- Mobile-friendly navigation: Overview, Moderation, Warnings, Activity log, Settings.
- Bot capability overview for the existing documented commands.
- Explicit placeholder states where live data is not connected.
- No separate username/password form: the intended experience is inside Root.
- Moderation controls are labelled as prototype-only and do not execute community actions.

## Next steps before production

1. Create a separate Root App project using the official starter command: `npx create-root --app VelceronDashboard`.
2. Move/adapt `VelceronDashboard.tsx` into the generated App client's React/TypeScript entry point.
3. Add a Root App server and use only documented Root APIs for authenticated, community-scoped data.
4. Determine a supported integration strategy between the separately hosted Root App and the existing Root Bot. Do not assume the two apps share a database or can call each other directly.
5. Add server-side permission checks for every moderation operation, then test in a development community before publishing.

## Build and safety notes

- This component has not yet been built inside the official Root App starter, so it is not a publishable Root App package on its own.
- Metric values and status labels are placeholders, not live community data.
- Do not expose a bot token or `DEV_TOKEN` in client-side code.
- Keep the existing bot manifest and source unchanged until the new App is independently built and tested.
